## 3. 审计发现

### A1（必须修）缺少 `model_prefix_policy`

Provider 规格明确 `opencode-go/` 前缀需要规范化，但本规格 DDL 未包含该字段。补列：

```sql
ALTER TABLE llm_profiles ADD COLUMN IF NOT EXISTS model_prefix_policy TEXT NOT NULL DEFAULT 'strip';
```

并规定：若模型名含 `/`，取最后一段；仅当 `model_catalog` 为空或包含该段时接受。

### A2（必须修）缺少 `session_id` 生成规则

OpenCode Go 要求 `x-opencode-session`。补：`session_id = f"scan-{scan_id}-{agent}-{profile_id}"`；无 scan 时用 `probe-{uuid4().hex[:8]}`；不得包含用户名、密钥或代码内容。

### A3（必须修）缺少 schema 懒加载

新表只在 `init-db` 时创建；现有测试与开发库不会自动迁移。补 `control/bootstrap.py::ensure_control_schema()`：首次控制面调用或 `run_scan_graph` 开始时执行幂等 DDL（带进程内缓存与失败降级）。测试环境也可直接调用。

### A4（实现风险）唯一 active 索引与现有写入冲突

`admin_api.create_prompt` 与 `rollback_prompt` 目前直接插入 `active=TRUE`，历史数据可能多 active。规格已写迁移收敛，但未写写入路径改造。补：创建/回滚必须在事务内先 `UPDATE prompt_versions SET active=FALSE WHERE agent=%s` 再插入；否则唯一索引会报错。

### A5（范围标注）自定义 Agent 未覆盖

FR-21 要求“内置 + 自定义 Agent 定义（版本化）”。本规格只覆盖六内置。将自定义 Agent 定义与 Bundle 导入导出标注为 **M6.6 推迟**，避免本轮范围失控。

### A6（范围标注）Prompt A/B、评测、Skills 审批、重放推迟

与需求里程碑表一致，但需在规格 §2.2 明确列出，避免验收争议。

### A7（安全）旧密钥仍在 git 历史

`tests/test_opencode_probe.py` 在 `a44fa1a`、`0e2eb11` 中已提交真实密钥。本轮只能移除工作区明文并改为环境变量；**历史清理需单独授权**（filter-repo/BFG），且密钥必须立即轮换。规格需写明。
