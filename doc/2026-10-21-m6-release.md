## 3. 运行

```bash
docker compose up -d
uv sync
uv run codesentry init-db
uv run codesentry serve --host 127.0.0.1 --port 8000
# 控制台：http://127.0.0.1:8000/ui/
```

认证开启：

```bash
export CODESENTRY_AUTH_ENABLED=true
export CODESENTRY_SECRET_KEY="$(python -c 'import secrets;print(secrets.token_urlsafe(32))')"
export CODESENTRY_ADMIN_PASSWORD='change-me'
uv run codesentry user create admin --admin
```

沙箱/PoC：

```bash
export CODESENTRY_POC_RUN=sandbox   # 默认 off；off 时 deploy 只 built、PoC 最高 plausible
```
