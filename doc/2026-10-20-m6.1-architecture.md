# M6.1 平台基座架构说明

> 日期：2026-10-21。对应规格：`doc/2026-10-20-m6.1-platform-foundation-spec.md`。
> 本文档描述 M6.0–M6.5 落地后的模块边界、数据流与扩展点：控制面、Agent 基座、LangGraph 内核（checkpointer/interrupt/Send/artifacts）、Docker 沙箱部署、PoC canary 实证、置信度校准、Vue 3 控制台。

## 1. 分层

```
web/                     HTTP 契约与认证中间件
  server.py              应用、上传、扫描、设置、SPA 托管（catch-all 最后注册）
  admin_api.py           既有管理面板（agents/prompts/skills/rules/reviews）
  control_api.py         M6.1 控制面（profiles/agents/usage/audit/health）
  auth_api.py            login/logout/me/users/api-tokens + 全局中间件
        │
control/                 配置与台账服务（不依赖 FastAPI）
  bootstrap.py           幂等 schema 懒加载
  profiles.py            LLM Profile CRUD / 默认 / fallback / 探测
  agent_config.py        Agent 默认值 / 绑定 / 能力矩阵 / 统计
  prompts.py             版本 / 激活 / 回滚 / diff / lint
  skills.py              分配 / 版本固定 / 注入预览 / 使用追踪
  usage.py               llm_usage 写入、聚合、配额
  audit.py               config_audit 写入/查询（脱敏）
  auth.py                用户 / JWT / API Token / 路径策略
        │
agents/
  llm.py                 OpenAI/Anthropic 双协议、Profile 构造、重试、用量
  runtime.py             AgentRuntime：Prompt + Skills + LLM + 能力
  triage.py / poc_gen.py 消费 runtime
        │
orchestrator/
  registry.py            节点元数据与默认节点
  graph.py               LangGraph 组图 + runtime 注入
  runner.py              扫描落库、快照、执行、findings 落库
        │
security/secrets.py      Fernet 主密钥、加密、掩码、脱敏
```

依赖方向：`web → control/agents/orchestrator → db/security`。`control` 不导入 `web`，`agents` 不导入 `web`。

## 2. 扫描数据流

```text
Web 上传
  → server._insert_scan（scans.status=running）
  → run_scan_graph(scan_id=…)
      → ensure_control_schema()
      → _snapshot_agents()：prompt_snapshot / skill_snapshot / llm_snapshot
      → UPDATE scans 固定快照
      → build_graph()（registry 默认节点）
          recon → scan → retrieval → triage → poc_gen → [human_review] → report
      → 每个节点 _wrap：
          prepare_agent(node) 解析 Prompt/Skills/LLM/能力
          注入 runtime（仅函数签名声明 runtime 时）
          node_run 遥测 + BudgetGuard + LLM token 回流
      → findings 落库
```

快照在扫描开始时固定；运行中修改 Prompt/Skill/Profile 不影响本次扫描（NFR-2）。

## 3. LLM 调用链

```text
prepare_agent(agent)
  → agent_config.get_agent_config（缺失用默认）
  → prompts.load_prompt（DB 生效版本；失败回退种子）
  → skills.load_assigned_skills（priority / version_pin）
  → build_context_block（8K/32K 截断 + 告警）
  → effective_capabilities（POC_RUN=off 时关闭 poc_gen 的 network/shell/poc_exec）
  → LLMClient.for_agent
        → profiles.resolve_profile：Agent 绑定 → fallback → 默认 → .env
        → 逐模型协议：model_protocols[model] → profile.protocol
        → complete()：OpenAI /chat/completions 或 Anthropic /messages
        → usage.record_usage（tokens/cost/latency/ok）
```

错误分类：`MissingSessionID` 配置错误、`ModelProtocolUnsupported` 协议错误（尝试另一协议一次）、模型不可用切 fallback、429/5xx 指数退避。

## 4. 认证与权限

- 默认 `CODESENTRY_AUTH_ENABLED=false`，本地单机模式开放；开启后中间件对所有 `/api/*`（`/api/auth/login`、`/api/health` 除外）校验身份。
- 角色：`viewer < analyst < admin`；`ci` 由 API Token scope 决定。
- 配置写（profiles/agents/prompts/skills/rules/settings/users/tokens/usage）要求 admin；扫描创建/复核要求 analyst+；读取配置要求 analyst，读取扫描/报告允许 viewer。
- 密码 `scrypt`；JWT HS256（主密钥派生）存 HttpOnly Cookie，12h；API Token `cs_<prefix>_<secret>` 仅创建时返回一次，库存 SHA-256。
- `CODESENTRY_ADMIN_PASSWORD` 可在认证开启且无用户时引导管理员；也可用 `codesentry user create --admin`。

## 5. 密钥与审计

- `CODESENTRY_SECRET_KEY` 存在时派生 Fernet/JWT 密钥；否则使用 `<work_dir>/.secret_key`（0600，自动生成）。
- Profile 密钥加密存 `llm_profiles.api_key_cipher`；读接口只返回前 8 位 + `…`；更新时空值保留原值。
- `config_audit` 记录 actor/action/target/before/after；`api_key/secret/password/token` 字段递归替换为 `***`。
- 日志、报告、配置导出不得包含完整密钥。

## 6. 无库/降级

| 场景 | 行为 |
|---|---|
| DB 不可用（控制面） | `ensure_control_schema` 返回 False；列表返回空集；写入返回 503 或 False |
| DB 不可用（扫描） | 落库失败仅告警；报告仍产出；runtime 回退 `.env` 或 `llm=None` |
| LLM 不可用 | 节点收到 `llm=None`；triage 保留引擎结论，PoC 最高 plausible |
| Profile 未绑定 | 默认 Profile → `.env` → 无 LLM 降级 |
| Agent disabled | 节点返回 skipped 语义（保留/不生成），链路继续 |
| `POC_RUN=off` | DeployAgent 后续只构建；本轮 PoC 全部 plausible |

## 7. 扩展点

- **新增 Provider**：在 `control/profiles.PRESETS` 增加预设；如需新协议，在 `LLMClient` 增加 `_call_*` 与 `model_protocols` 映射。
- **新增 Agent**：在 `agent_config.AGENT_DEFAULTS` 与 `orchestrator/registry.NODE_SPECS` 注册；节点函数签名声明 `runtime=None` 即自动注入。
- **新增节点**：注册 NodeSpec 并在 `graph.build_graph` 加边；模板化编排（M6.6）将从此注册表编译。
- **新增审计对象**：写操作调用 `audit.audit_write`，before/after 自动脱敏。
- **新增角色/路径**：在 `control/auth.required_role` 增加策略；中间件统一执行。

## 8. M6.2–M6.4 增量（后端）

| 模块 | 职责 |
|---|---|
| `sandbox/deploy.py` | 语言配方（python/php/js）、Docker 容器/独立 bridge、资源限额、健康探测、清理；`POC_RUN=off` → `built` |
| `sandbox/verify.py` | PoC 自身声明 `{CANARY_CMD}` / `{CANARY_FILE}` / `{CANARY_URL}` 后产生实证；无占位符最高 plausible |
| `orchestrator/artifacts.py` | 节点输入/输出摘要 + SHA-256 + `prev_sha256` 哈希链；校验/篡改检测 |
| `agents/confidence.py` | raw / evidence / calibrated / verdict-gated 四层置信度 |
| `control/calibration.py` | 温度缩放 a/b 网格拟合 + ECE |
| `control/orchestration.py` | graph_templates 校验/版本/激活（执行仍走默认主链） |
| `web/server.py` | `GET /api/scans/{id}/sarif`、`POST /api/scans/{id}/replay` |
| `web/control_api.py` | artifacts 查询/校验、calibration、graph-templates、prompt-evals |

图链路：`recon → scan → retrieval → triage → deploy → poc_gen → [human_review] → report`；`POC_RUN=off` 时 deploy 只记录 `built`，不启动服务。
