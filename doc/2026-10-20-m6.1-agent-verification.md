## 2. 关键行为说明

### 2.1 绑定解析

```
agent_configs.llm_profile_id
  → profile.enabled ? 使用
  → profile.fallback_profile_id（enabled）? 使用
  → llm_profiles.is_default（enabled）? 使用
  → Settings(.env)
  → 无 LLM：节点降级（triage 保留引擎结论，PoC 最高 plausible）
```

### 2.2 运行时上下文

`prepare_agent(agent, snapshot=...)`：

1. 读 Agent 配置（缺失时 seed 默认值）。
2. Prompt：快照 `version` 精确加载；无快照时读 active 版本；无 DB 回退种子并告警。
3. Skills：快照 `name/version` 精确加载；无快照时按 assignment 的 `version_pin`/`priority` 解析。
4. LLM：快照 `profile_id` 优先；否则走绑定解析链。
5. 能力矩阵：`POC_RUN=off` 时强制关闭 `poc_gen` 的 network/shell/poc_exec。
6. 返回 `system_prompt`、`skills_block`、`prompt_version`、`profile_id`、`warnings`。

### 2.3 禁用语义

- `triage`/`poc_gen`：节点函数收到 `runtime.enabled=false`，保留/不生成，链路继续。
- `recon`/`scan`/`retrieval`/`report`：`graph._wrap` 直接跳过并写 `node_runs.status='skipped'`；`report` 禁用时 phase=done。
- 所有跳过都会在 `state.messages` 留下审计消息。

### 2.4 快照不可变

扫描创建时写入 `prompt_snapshot`（含 sha256）、`skill_snapshot`（name/version/sha256）、`llm_snapshot`（profile/provider/protocol/models）与 `graph_snapshot`。运行时只读快照；扫描期间修改 Prompt/Skill/绑定不会影响本次执行。

## 3. 真实 Provider 冒烟

脚本：`scripts/live_agent_smoke.py`（不内置密钥）。用法：

```bash
export OPENCODE_GO_API_KEY='<your-key>'
PYTHONPATH=src .venv/bin/python scripts/live_agent_smoke.py \
  --base-url https://opencode.ai/zen/go/v1 --model qwen3.8-flash
```

脚本会：

1. 创建临时 `opencode-go` Profile（密钥加密落库，不进日志）。
2. 绑定 `triage`。
3. `prepare_agent("triage")` 打印绑定 Profile、Prompt 版本、Skills。
4. 对一个 SSRF 样例 finding 调用一次真实 Triage，打印 verdict/confidence/tokens。
5. 清理临时 Profile、绑定与用量。

> 实测结果（2026-10-20）：临时 `.env.live`（0600、gitignored，用后删除）提供密钥，脚本成功执行：
> 绑定 Profile、注入 Prompt/Skills、OpenCode Go `qwen3.8-flash` 返回 `verdict=keep` / `confidence=0.95`，
> `prompt_tokens=295`、`completion_tokens=385`，脚本自动清理临时 Profile 与用量。
> 直接在执行命令中携带密钥会被安全分类器拦截，这是预期的密钥保护；请使用环境变量或临时 env 文件。
