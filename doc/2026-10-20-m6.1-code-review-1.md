## 2. 关键问题与处置

### F1（Critical）`/ui/` 路径穿越任意文件读取

- 位置：`src/codesentry/web/server.py` `root_fallback`
- 现象：`STATIC_DIR / spa_path[len("ui/"):]` 未做边界校验，`/ui/%2e%2e/server.py` 可读出静态目录外文件。
- 处置：`candidate.resolve()` 后 `relative_to(_STATIC_ROOT)` 校验；越界返回 404。
- 回归：`tests/test_web_spa.py::test_ui_path_traversal_rejected`。

### F2/B5（High/Medium）`/assets` 挂载被 catch-all 截获

- 位置：`server.py` 静态托管块
- 现象：`@app.get("/{spa_path:path}")` 先注册，`app.mount("/assets")` 后注册，`/assets/*.js` 404。
- 处置：先 `mount`，后注册 catch-all；同时保留 `/ui/assets/*` 文件服务。
- 回归：`test_root_assets_mount_served`。

### B1（High）Agent 默认配置未落库，更新静默丢失

- 位置：`control/agent_config.py`
- 现象：`ensure_agent_configs()` 无生产调用方；`update_agent_config` 只 UPDATE，fresh DB 下 0 行受影响却返回默认值。
- 处置：`get_agent_config` 入口幂等调用 `ensure_agent_configs()`；`init-db` 也显式 seed；更新失败返回 `None`，API 映射 503。
- 回归：`tests/test_agent_config.py`、`tests/test_control_api.py`。

### B2（High）扫描快照不可变（NFR-2）

- 位置：`orchestrator/graph.py`、`runner.py`、`web/server.py`、`agents/runtime.py`
- 现象：节点运行时重新读取实时 Prompt/Skill/Agent 配置，与扫描开始时的快照不一致。
- 处置：
  - 新增 `control/snapshots.py::build_scan_snapshot()`，上传时与扫描启动时写入 `prompt_snapshot/skill_snapshot/llm_snapshot`。
  - `runner` 复用已存快照，不覆盖非空快照。
  - `graph._wrap` 将快照传入 `prepare_agent`。
  - `prepare_agent` 按快照 `version` 精确加载 Prompt/Skill，并优先使用快照中的 `profile_id`。
- 回归：`tests/test_agent_runtime.py::test_snapshot_pins_prompt_version`、`tests/test_web_server.py::test_upload_reuses_scan_row_and_writes_snapshots`。

### F3（Medium）禁用用户后 API Token 仍有效

- 位置：`control/auth.py::verify_api_token`
- 处置：LEFT JOIN `users`，`user_id` 非空且 `enabled=false` 时拒绝。
- 回归：`tests/test_auth.py`（用户禁用场景可扩展）。

### F4（Medium）Cookie 缺少 `Secure`

- 位置：`web/auth_api.py::login`
- 处置：HTTPS 或 `X-Forwarded-Proto: https` 时设置 `secure=True`。

### F5（Medium）仅 triage/poc_gen 支持 disabled

- 位置：`orchestrator/graph.py::_wrap`
- 处置：recon/scan/retrieval/report 在 `_wrap` 中检查 `agent_configs.enabled`；禁用时记 `node_runs.status='skipped'` 并继续链路；report 禁用时 phase=done。
- 回归：`tests/test_graph_runtime.py::test_disabled_non_llm_node_is_skipped`。

### F6（Low/Medium）LLM 错误分类过宽

- 位置：`agents/llm.py::_classify`
- 处置：优先读取 `status_code`/`HTTP xxx`；401/403/404/未知 4xx 归配置错误不重试；429/5xx/连接错误重试；仅 `model is unavailable` 归不可用。

### F7/B8（Medium）失败调用未写入 llm_usage

- 位置：`agents/llm.py::_complete_inner`
- 处置：配置/协议/不可用/重试耗尽路径均写 `ok=false` + `error`。

### F8（Low）主密钥文件生成竞态

- 位置：`security/secrets.py`
- 处置：`os.open(O_CREAT|O_EXCL, 0o600)` 原子创建；`FileExistsError` 时复用既有文件。

### F9（Low）登录硬化

- 位置：`web/auth_api.py`、`control/auth.py`
- 处置：密码最少 8 位；登录失败 5 次/5 分钟限流（按 client+username）；`/api/auth/logout` 移入公开路径，过期会话也能清 Cookie；登录同时接受 JSON 与表单。

### B3（High/Medium）无库路径超时

- 位置：`db/pool.py`、`control/bootstrap.py`、`runner.py`
- 处置：`ensure_control_schema` 改为直连 + `connect_timeout=3`；连接池 acquire `timeout=5s`；快照构建在 schema 不可用时立即返回空。

### B4（Medium）写失败报成功

- 位置：`control/agent_config.py`、`web/control_api.py`
- 处置：更新失败返回 `None` → 503；用户更新区分 404/503。

### B6（Medium）用量接口 `from/to` 契约

- 处置：`/api/usage/summary` 增加 `from`/`to` 别名。

### B7（Medium）Profile probe 未做逐模型协议

- 处置：`probe_models(profile_id, limit=5)` 拉取 `/models` 后对前 N 个模型尝试 OpenAI/Anthropic 协议，写回 `model_catalog`、`model_protocols`、`capabilities.probed`。默认限制 5 个，避免过量调用。

### B9（Medium）Skill preview 忽略 name

- 处置：`preview_injection(..., only={name})` 过滤。

### B11（Low）失败扫描长期 running

- 位置：`runner.py`
- 处置：findings 写入后无论成败都 `UPDATE scans SET status, error_reason`；图执行异常也写 `error_reason`。

### B12（Low）快照/会话/遥测缺口

- `prompt_snapshot` 增加 `sha256`；`scans.llm_profile_id`/`graph_snapshot` 写入；`session_id` 包含 profile id；`node_run` 改为产出可变 `NodeRun`，节点结束后回填 tokens，`node_runs.tokens` 不再恒为 0。

### B13（Low）兼容性细节

- `/api/prompts/{name}/versions` 同时返回 `created` 与 `created_at`。
- 新增 `codesentry serve`，使用 `web_bind` 并在非回环 + 未认证时告警。
- CLI 改为 `codesentry user create <name> --admin`。
- 登录支持表单。

### B14（Low）Profile 配置错误跳过 `.env`

- 处置：`for_agent` 在 Profile 构造失败时先尝试 `from_config()`，再抛出原错误。

## 3. 已知限制（不阻塞本轮）

1. **测试共用开发库**：测试未使用独立 schema/数据库；本轮通过唯一名称、清理与顺序执行控制，后续引入 testcontainers 或专用测试库。
2. **登录限流为进程内**：多 worker 部署需改为 Redis/DB 计数；本轮单机模式可接受。
3. **主密钥轮换未批量重加密**：spec §12 风险已记录；轮换后旧密文返回 `***` 并需重新录入。
4. **Probe 默认只探测前 5 个模型**：避免订阅配额消耗；可在后续 UI 中显式扩大。
